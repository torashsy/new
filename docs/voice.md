# 文体とキャプション

## 前提：この文書の出どころ

ここに書いたことの根拠は2種類あって、**信頼度が違う**。区別して扱うこと。

| 根拠 | 信頼度 | 中身 |
|---|---|---|
| Web検索で確認できた事実 | 高 | ハッシュタグ上限、キャプションの表示文字数など、仕様の話 |
| 一般的なSNS運用記事からの推論 | 低 | 「20代女性はこういう文体を好む」系。**出典はマーケ会社のSEO記事であって、実際の投稿の分析ではない** |

実在のアカウントの投稿を直接収集して分析したものではない。
精度を上げるには、参考にしたいアカウントを実際に見て、下の「分解シート」を手で埋める必要がある。

---

## 確認できた仕様（2026-08時点）

- **ハッシュタグは1投稿あたり最大5個**。2025年12月19日から Instagram 公式のハードキャップ。超過分は削除されるか投稿が弾かれる。キャプションに書いてもコメント欄に書いても同じ。
- キャプションの上限は2,200文字。ただし**フィード上で最初に見えるのは40-60文字程度**で、それ以降は「続きを読む」の裏。
- 「#〇〇 を30個並べる」時代の運用ノウハウは全部無効。

---

## 設計方針：運用ノウハウの逆を行く

SNS運用記事が推奨する型はこれ。

> ①フック（1行目）→ ②本文（価値提供）→ ③CTA → ④キーワード＆ハッシュタグ

**このアカウントでは全部使わない。** 理由は単純で、23歳の会社員は自分のインスタでこんな構成の文章を書かないから。
この型は「フォロワーを増やしたい人」の書き方であって、「今日あったことを上げている人」の書き方ではない。

### 守ること

| 項目 | 指定 |
|---|---|
| 文字数 | **15-60字が主体**。たまに1行（10字以下）、月1-2回だけ150字程度の長め |
| 1行目 | フックを置かない。**いきなり本文から始める** |
| 改行 | 0-2回。空行を作った整形はしない |
| ハッシュタグ | **0-2個**（上限5だが、等身大アカで5個並べると宣伝臭が出る）。半分の投稿は0個 |
| 絵文字 | 0-1個。連続で置かない |
| CTA | **禁止**。「保存してね」「コメントで教えて」は一切書かない |
| 呼びかけ | 禁止。「皆さん」「みんなは」を使わない |
| 語尾 | 「〜した」「〜かも」「〜な気がする」。**丁寧語（〜しました）は使わない** |
| 言い切り | 避ける。文の途中で終わる、句点を打たない投稿も混ぜる |

### 書かないこと

- 情報のまとめ（「〇〇3選」「保存推奨」）
- 商品のスペック説明（値段は書いてもいい。**理由や比較は書かない**）
- 自己啓発っぽい総括（「頑張ろう」「自分を大切に」）
- ハッシュタグの羅列
- 誰かへの感謝

---

## 語彙のルール

`persona.json` の `personality.speech_habits` に対応する。

**使う**
- 「〜かも」「〜な気がする」「たぶん」（断定を避ける）
- 自分へのツッコミ（「また買った」「懲りない」）
- 具体的な固有名詞（コンビニのプリン、電車の駅名）── ただし**勤務先が特定できるものは除く**

**使わない**
- 「〜させていただく」
- 「幸せ」「癒し」「至福」（感情の直接表現）
- 「ぜひ」「おすすめ」
- 顔文字、記号の装飾（＊、♡、✧）

## キャプションの型（実作例）

平日投稿は21:30-23:30、休日投稿は11:00-14:00。時間帯が文体に出る。

### 平日（帰宅後・疲れている）

```
月曜からこれはきつい
```

```
残業。コンビニで済ませた
```

```
このブラウス週2で着てる
気づかれてないと思ってる
```

```
今日やっと一人で電話取れた
```

### 休日（余裕がある）

```
洗濯物が乾かない
```

```
何もしない日にした
```

```
久しぶりに高円寺
結局なにも買わずに帰ってきた
```

```
作り置きしたけど水曜には飽きる
たぶん
```

### 月1-2回の長め（150字程度）

```
上京して5年、まだ実家に帰ると
「痩せた?」って必ず言われる
別に痩せてない
こっちの生活が想像つかないだけなんだと思う
説明するのも面倒だから毎回そうかもって言ってる
```

### やってはいけない例

```
✗ 今日のコーデ🤍
  ホワイトブラウス×ブラックパンツで
  きれいめオフィスカジュアル✨
  参考になったら保存してね💐
  #オフィスカジュアル #20代コーデ #OLコーデ
  #きれいめコーデ #着回し #社会人2年目
```

フック、装飾絵文字、説明、CTA、ハッシュタグ6個（**上限違反**）。全部入っている。
これは運用アカウントの書き方であって、実在の23歳の書き方ではない。

## 分解シート（精度を上げるための作業）

参考にしたいアカウントが決まったら、直近20投稿についてこれを手で埋める。
これを埋めないかぎり、上の文体設計は**推論のまま**。

| 項目 | 記録すること |
|---|---|
| 文字数 | 20投稿の実測値と中央値 |
| 1行目 | フックがあるか、いきなり本文か |
| 改行 | 回数の分布 |
| ハッシュタグ | 個数の分布、種類 |
| 絵文字 | 個数、種類、位置 |
| 語尾 | 常体/敬体、断定/非断定の比率 |
| 投稿間隔 | 日付の実測、曜日の偏り |
| 投稿時刻 | 時刻の分布 |
| 構図 | `docs/shooting-guide.md` の8パターンのどれか、その配分 |
| 完成度 | 「決まっている/普通/雑」の枚数 |
| 顔の露出 | 顔出しあり/一部/なし の比率 |
| カルーセル | 枚数の分布、2枚目以降の雑さ |

**収集した他人の投稿そのもの（スクショ等）はリポジトリに入れない。** `.gitignore` で `research/raw/` を除外済み。
リポジトリに入れるのは、上の表に集計した**数値と傾向だけ**。
